Privacy Policy: Faceless YouTube Tools

Last updated: November 18, 2026

What this app is

Faceless YouTube Tools is a private tool used only by the owner of the YouTube channel "Why You Do That" to upload that channel's own videos and read its own statistics. It runs on one personal computer and is not offered to other users.

What data it accesses

  • YouTube upload permission (youtube.upload): to upload the channel's own videos with their titles, descriptions and tags.
  • YouTube read-only permission (youtube.readonly): to read the channel's name, subscriber count and its videos' view, like and comment counts.

It does not read, store or process any other person's data, comments, messages, email or contacts.

How data is stored

The sign-in tokens Google issues are saved only in a private file on the owner's computer. Channel statistics are saved as small report files on the same computer. Nothing is sent to any server other than Google's own YouTube API.

Sharing

No data is sold, shared or transferred to anyone. The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the computer also ends access.

Contact

Questions can be sent through the "Why You Do That" YouTube channel.
